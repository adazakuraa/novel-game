## 1. 世界観 【未決：Q-A1〜A7】

### 【提案】世界コンセプト候補

| 案 | 骨子 | 長所 | 注意点 |
|---|---|---|---|
| α「残灯の時代」 | 数百年前に古代魔法文明が崩壊。現在は遺跡の遺物と再発見された魔法で復興の途上にある。ギルドは遺跡探索と魔物対処のために生まれた | 研究・遺跡・魔法理論・歴史の謎が一本の軸でつながる | 「古代文明の謎」は王道ゆえに独自の切り口が要る |
| β「境界の街」 | 人の領域と魔境の境にある辺境都市。魔境は周期的に満ち引きする（潮） | 舞台を一都市に絞れてMVP向き。季節やイベントに周期が生まれる | 世界の広がりは拡張段階で出す必要がある |
| γ「褪せる魔力」 | 世界の魔力がゆっくり減り続けている。国家・魔導院・ギルド・商会の思惑が交錯する | 社会構造・経済・政治のドラマが作りやすい | 重いテーマなので日常の温かさとの釣り合いが要る |

**推奨：α＋β の融合**。開始舞台は「古代文明の遺跡群と魔境に接する辺境都市」。魔境の潮と遺跡の発掘が、経済・職業・危険・歴史の謎を一つの因果でつなぐ。γ の要素（魔力資源の問題）は世界の深層の秘密として温存する。

### 【提案】世界設計の原則
- あらゆる設定に「それがあるから何が起きるか」（経済・職業・NPCの生活への影響）を書く
- 年表は「世界の時計」としてデータ化し、主人公が関与しなくても進む

## 2. 主人公・人生・職業 【未決：Q-B1〜B8】

### 【提案】職業モデル：所属 × 肩書き の二層
- **所属**（公的なもの）：冒険者ギルド、騎士団、魔導院、錬金工房、商会、施療院など。義務（時間拘束・ノルマ）、権利（依頼・設備・師）、上下関係、昇格がある。複数所属もできるが、時間と義務で自然に制約される。
- **肩書き**（社会が認めるもの）：行動実績からNPCや社会が主人公をどう見るか（「あの薬草に詳しい冒険者」）。イベント・依頼・会話を変化させる。
- 転職＝所属の変更。過去の所属歴・人脈・技能は残る（元騎士の冒険者、など）。

## 3. 時間 【未決：Q-B7, B8】
- 【確定】1日＝朝・昼・夕方・夜
- 【提案】各区分で基本1行動。短い行動（食事・会話）は区分内で組み合わせられる。遠征は日単位。週ごとのルーチン登録で作業感を減らす。

## 4. 能力・才能・成長の内部モデル 【未決：Q-D1〜D7】

### 【提案】7層モデル

| 層 | 内容 | 表示 |
|---|---|---|
| 素質 | 分野ごとの伸び率と天井（ランダム生成の中心） | 非表示 |
| 基礎能力 | 身体（筋力・持久・敏捷・器用）、精神（意志・集中・平静）、知性（記憶・分析・直観）、社会（共感・弁舌・存在感） | 描写のみ |
| 技能 | 剣術・魔法系統・薬学など。**実技**と**理論**の二面を持つ | 自己認識の語彙 |
| 知識・理解 | 個別の知識（「岩喰い虫の弱点」）や原理の理解。フラグ型 | 日誌・図鑑 |
| 経験記録 | 戦った相手、修羅場、旅した土地、立ち会った出来事 | 回想・日誌 |
| 傾向 | 慎重/大胆、几帳面/直感的など。行動から形成 | 他者の評 |
| 状態 | 体調・疲労・負傷・気分・空腹・ストレス | 描写＋簡易アイコン（要検討） |

### 【提案】成長の算出原理
1. **適正負荷**：今の実力に対して難しすぎず易しすぎない経験ほど伸びる（格上との実戦は伸びるが危険）
2. **新規性の逓減**：同じ行動の繰り返しは効果が落ちる。変化をつけると回復する
3. **質**：集中・体調・指導者・設備・道具が掛け算で効く
4. **成功と失敗**：失敗からも学ぶが、伸びる部分が違う（失敗は理解と慎重さ、成功は自信と定着）
5. **定着**：経験はまず「未定着」として蓄積し、睡眠や休息で能力に反映される。休まない無理は伸びにくく、怪我のもとになる
6. **停滞と突破**：技能ごとに「壁」がある。実技・理論・実戦・指導など**異なる種類の経験の組み合わせ**で突破し、突破は印象的なイベントとして描写する
7. **相互作用**：基礎能力が技能の伸びを支える（持久がないと剣の型の練習量が積めない、など）
8. **錆び**：使わない技能の勘は鈍るが、天井は下がらず、すぐ戻る

### 【提案】初期能力ランダム生成
- 「才能の型」（例：天性の体躯/魔力の器/明晰/不屈/器用/大器晩成＝伸び率が高く初期値が低い）を1〜2個抽選し、細部をランダムで決める
- 素質の合計を一定範囲に正規化して、極端な不公平を防ぐ
- 「何もかも平凡」の型には、努力の効率（定着率・逓減の緩さ）で補償する

## 5. 行動システム 【未決：Q-C1〜C5】

### 【提案】行動組み立て（アクション・コンポーザー）
`場所 → 活動 → 方法 → 対象/重点 → 同行者 → 道具` を順に絞り込む。各段は前段で有効な候補だけを出す。

例：訓練場 → 剣術 → 模擬戦 → 「受け流し」重点 → 同期のNPCと → 木剣

- 内部では「行動テンプレート × 修飾子」として解決する。組み合わせの数がそのまま自由度になる
- 未知の組み合わせにも汎用の描写と成長処理が働くようにし、特別な組み合わせにだけ専用イベントを用意する

### 【提案】自由入力（AIなし）の技術的限界

| 実現できる | 実現が難しい |
|---|---|
| キーワード・同義語辞書で入力を解析し、該当する行動の候補を提示する | 任意の文章の意味理解 |
| 「〜で〜を練習する」のような定型文法の解析 | 想定外の行動に対する固有の結果生成 |
| 合致しない入力には「近い行動」を提案する | NPCとの自由会話 |

→ 自由入力は**行動検索・ショートカット**の位置づけを推奨する。会話は話題選択式にする。

## 6. NPC・人間関係 【未決：Q-E1〜E6】

### 【提案】NPCモデル
- **関係軸**：信頼／親しみ／尊敬／恩義（貸し借り）／警戒／敵意／嫉妬・競争心（＋恋愛は Q-A7 で決定）。一度の出来事で動く量に上限を設け、積み重ねを重視する
- **一時感情**：その日の機嫌。NPC自身の出来事でも変わる
- **記憶**：主人公との重要な出来事・約束・発言をタグとして保存し、後の会話やイベントで参照する
- **人生の進行**：NPCごとの目標・悩みが週単位で進む（主人公が関わらなくても状況が変わる）
- **スケジュール**：曜日×時間帯で居場所が決まる。例外イベントあり
- **NPC間の関係**：主要NPC同士にも関係軸を持たせる

## 7. ストーリー 【未決：Q-F1〜F6】

### 【提案】4層構造
1. **世界の時計**：主人公と無関係に進む大事件の年表。関与すれば結果が変わる
2. **主要アーク**：世界の謎・危機に関わる物語。関わる度合いはプレイヤー次第
3. **人物アーク**：主要NPCごとの長編
4. **ストーリーレット**：条件（能力・履歴・関係・場所・時間・世界状態）で発生する短編・日常イベント。失敗や小さな選択の結果を拾う

## 8. 戦闘・冒険・探索 【未決：Q-G1〜G7】

### 【提案】戦闘モデル
- **距離帯**（遠・中・近・密着）、**体勢**、**地形タグ**（足場・遮蔽・高所・水など）、**準備**（事前の調査・罠・道具）
- **敵の予兆**：敵は次の行動を描写でほのめかす。**主人公の経験・知識が高いほど予兆が正確に読める** → 成長を実感する中心の仕組み
- 行動：攻撃・防御・移動・観察・道具・魔法・会話・撤退
- 結果は描写で返す（命中率は非表示、「手応え」で伝える）
- 負傷は部位と重症度で管理し、後遺症の可能性もある

### 【提案】探索
- 地域ごとに地点のつながり（ノードグラフ）を持ち、移動で時間と物資を消費する。地点ごとにイベントと採取が発生する
