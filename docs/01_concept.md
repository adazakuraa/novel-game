# 01. 基本構想の整理（第1段階 成果物）

- 版: v0.1（2026-11-13）
- 状態: 依頼者の構想指示書を整理したもの。設計判断はまだ含まない（提案は `02_requirements.md` に分離）。

---

## 1. 一行コンセプト（暫定）

> 剣と魔法の世界で、新人として生き始めた一人の人間が、日々の生活・鍛錬・研究・冒険・人間関係を積み重ね、
> 「数字ではなく経験として」成長していく。何者になるかは、プレイヤーが生き方の中で見つける。

## 2. ジャンル構成

| 要素 | 役割 |
|---|---|
| ノベル | 体験の提示方法（描写・会話・選択）。没入の中核 |
| 育成シミュレーション | 時間配分と行動計画、隠れた成長モデル |
| RPG | 冒険・探索・戦闘・リスク、世界への影響 |

## 3. 優先順位（依頼者指定・不変）

1. **ストーリーの質** — 長期的一貫性、因果の持続、失敗も物語化、日常にも物語性
2. **成長システムの質** — 行動の内容・質・頻度・状況・適性が成長を決める。数値は見せない
3. **主要NPCのリアルさ** — 各自の人生・価値観・目的。関係は積み重ねで変化、多軸

## 4. 構想上の確定事項（依頼者の指示から確定とみなすもの）

| ID | 内容 |
|---|---|
| C-01 | 舞台は剣と魔法・モンスター・冒険者ギルドのあるファンタジー世界（王道＋ハイファンタジー） |
| C-02 | 主人公は新人からスタート。過去・性格はある程度固定、価値観は行動で形成 |
| C-03 | 初期能力値はプレイ開始時にランダム決定。極端な不公平を避ける |
| C-04 | 職業は社会的立場・活動範囲・人脈・依頼・習得技術に影響。転職・複数分野を検討 |
| C-05 | 経験値・成長条件・能力数値は原則非表示。成長は描写・評価・成果で伝える |
| C-06 | ただし成長が全く把握できない状態は避ける |
| C-07 | 行動は複合的に組み立てる（場所・目的・方法・対象・道具・同行者・重点） |
| C-08 | 1日は朝・昼・夕方・夜の4区分。時間経過でNPCと世界が変化 |
| C-09 | 戦闘は描写＋戦術選択のターン制寄り。地形・距離・弱点・準備を考慮 |
| C-10 | 死亡あり。ただし理不尽な即死は不可。負傷・後遺症・依頼失敗・財産損失も検討 |
| C-11 | 主人公の発言は基本的にプレイヤーが選ぶ。正解・不正解の選択肢を作らない |
| C-12 | イベント分岐は能力・履歴・関係・選択・所持品・職業・時間・場所・世界状況の複合 |
| C-13 | 主要NPCは少数精鋭で作り込む |
| C-14 | 制作・公開・プレイのすべてが無料。ゲーム内での生成AI API呼び出しは禁止 |
| C-15 | スマホブラウザ主対象のWebゲーム。タブレット・PCでも動作 |
| C-16 | 端末内セーブ。セーブ/ロード・バックアップ・エクスポート/インポートを検討 |
| C-17 | 小さく作ってテストしながら拡張する |
