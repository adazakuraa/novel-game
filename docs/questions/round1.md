## A. 世界観・歴史・社会構造

- **A1★ 世界のトーン**：A 明るい王道 / B 命が重いリアル寄り / C ダーク / **D 日常は温かく、冒険と社会は厳しい（推奨）**
- **A2★ 世界の骨格**：α 残灯の時代（古代文明の崩壊後） / β 境界の街（魔境の潮） / γ 褪せる魔力 / **α＋β 融合、γ は深層の秘密として温存（推奨）** / 独自案
- **A3★ 舞台の広さ（当面）**：**A 辺境の一都市＋周辺地域に集中し、後で拡張（推奨）** / B 最初から複数都市 / C 大陸を旅する
- **A4 種族**：A 人間のみ / **B 人間中心＋少数の異種族（それぞれ独自の文化・立場）（推奨）** / C 多種族が対等に共存 / 主人公の種族選択：可・不可
- **A5 魔法体系**：**A 学問型（原理・術式を研究で深める）を主軸に、B 素質型や C 契約・信仰型を併存（推奨）** / 単一系統
- **A6 冒険者の等級**：**A 公的な等級制度＋昇級審査（数少ない「目に見える成長指標」になる）（推奨）** / B 評判のみ
- **A7 表現範囲**：恋愛（なし／控えめ／重要な要素）、流血・死・残酷描写の程度、想定する年齢層

## B. 主人公の人生と職業

- **B1★ 開始時点**（論点 R-01）：A 職業に就いた直後 / B 職業を選ぶ前（上京直後）/ **C 冒険者ギルドの仮登録の新人。他の道（魔導院・工房など）は出会いを通じて開く（推奨）**
- **B2★ 主人公の固定範囲**：A 名前・性別・外見すべて固定 / **B 名前・性別は選べる、出自と過去の出来事は固定（推奨）** / C 出自も数種から選べる
- **B3★ 主人公の動機の強さ**：A 強い個人的動機（行方不明の家族など、メインと直結） / B 生活のため（目標は自分で見つける） / **C 動機はあるが、追うかどうかはプレイヤー次第（推奨）**
- **B4 職業モデル**：**所属（公的な組織）× 肩書き（社会の評価）の二層（推奨）** でよいか／修正点
- **B5 職業の義務**：所属すると勤務時間・ノルマ・上下関係が生じる：**あり（推奨）** / 軽め / なし
- **B6 初期に実装する職業**：冒険者＋どれか（騎士・魔法使い/研究者・錬金術師・商人・職人・医師・独自案）。複数選択可
- **B7★ ゲームの期間とエンディング**：A 期限制（例：3〜5年）で人生を総括 / B 無期限 / **C 数年規模の章構成で総括エピローグを迎え、その後も継続できる（推奨）**
- **B8 1日の行動枠**：**各区分で1行動＋短い行動を併用、遠征は日単位（推奨）** でよいか

## C. 行動システム

- **C1★ 自由入力**：A 実装しない / **B 行動検索の補助として実装（後の段階）（推奨）** / C 主要な操作方法にしたい（限界は承知のうえ）
- **C2★ 計画方式**：A 1日分をまとめて計画してから実行 / B 区分ごとに選んで実行 / **C 両方＋週単位のルーチン登録（推奨）**
- **C3 生活管理の厳しさ**（空腹・疲労・病気・家賃・食費）：A 厳しい / **B 中程度（推奨）** / C 軽め
- **C4 行動結果の描写量**：A 毎回しっかり / **B 通常は短文、節目は詳細（推奨）** / C 最小限
- **C5 経済の深さ**：相場の変動・投資・店の経営などをどこまで扱うか（当面は浅め・将来的に拡張、を推奨）

## D. 能力・才能・成長

- **D1★ 7層モデルと成長原理**（`02_requirements.md` §4）：この方向でよいか／追加・削除したい要素
- **D2★ 才能の天井**：A 素質ごとに天井あり / B 天井なし（伸び率のみ） / **C 天井はあるが、努力・特別な経験・出会いで押し上げられる（推奨）**
- **D3 初期能力の生成**：**才能の型を抽選＋細部をランダム＋総量を正規化（推奨）** でよいか。リロール：無制限 / 回数制限 / 不可
- **D4★ 数値非表示の徹底度**（論点 R-03）：A 完全に非表示 / **B 非表示が基本、日誌に自己認識の段階語彙を出す（「ぎこちない」→「体に馴染んできた」）（推奨）** / C 抽象的な段階表示（見習い・熟練など）を常時表示
- **D5 プレイヤーが初期の才能を知る手段**：**序章の描写で示唆する（推奨）** / 鑑定イベント / まったく示さない
- **D6 衰え**：技能の錆び（**ありだが穏やか**、を推奨）。加齢による変化：あり・なし
- **D7 形成された性格と選択肢**（論点 R-08）：**A 選択肢は制限しない（反応・描写・判定にのみ影響）（推奨）** / B 極端な傾向のときだけ一部の選択に判定 / C 制限する

## F. メインストーリーと自由な人生

- **F1★ メインの強制度**：A 章ごとに強制イベントあり / **B 世界の時計方式（関わらなくても進み、結果が変わる。最低限の巻き込まれはある）（推奨）** / C 完全に任意
- **F2★ 物語の軸**：メインで描きたい問い・テーマの希望（例：才能と努力、過去との向き合い方、境界と共存、知ることの代償）。自由記述可
- **F3 エンディング**：**職業・人間関係・世界の結末・主人公の在り方を組み合わせたエピローグ型（推奨）** / 少数の固定エンディング
- **F4 失敗の扱い**：**メインの危機に失敗しても世界が変化した状態で続行できる（推奨）** / ゲームオーバー
- **F5★ 文体・視点**：A 一人称（主人公の内心を書くため、決めつけの危険が大きい） / **B 三人称限定視点（推奨）** / C 二人称「あなたは」
- **F6 ボリューム目標**：最終的なプレイ時間の目安（例：MVP 1〜2時間、最終 30時間以上）

## G. 戦闘・冒険・探索

- **G1★ 戦闘の比重**：A 頻繁にある主要素 / **B 重要だが少なめで、一戦一戦が重い（推奨）** / C 避けて生きることも可能（Bと併用可）
- **G2★ 操作の粒度**：A 毎ターン選択 / B 方針を指示して自動解決 / **C 雑魚は方針指示、強敵や節目はターン選択（推奨）**
