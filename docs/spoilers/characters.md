# 人物（ネタバレ）

## 主人公
- 南の農村ソラムの出身。16〜17歳。名前・性別・一人称はプレイヤーが決める。
- **7年前の大潮**で、森から溢れた澱狼の群れのはぐれがソラムまで流れてきた。一人の冒険者が狼を斬り、深手を負いながら去っていった。
  - 彼が落としていった、曲がった古い型の青銅の認識票を、主人公は今も持っている。札には「G」と刻まれている。
- 村の暮らしは苦しく、主人公は口減らしも兼ねてカルナスへ来た。
- 認識票の主を探すかどうかは、プレイヤー次第（B3：動機はあるが追うかは任意）。
- 地の文は一人称だが、感情を断定しない（F5 の対策）。感覚・行動・観察のみを書き、心情は選択肢で選ばせる。

## 主要NPC（MVP：4人、最大10人）

### ガラド（訓練場の教官）
- 48歳、元銀級冒険者。右膝に古傷があり、雨の日は足を引きずる。
- 寡黙で、教え方は荒い。口癖は「生きて帰った奴が強い」。
- **過去**：7年前の大潮のとき、パーティー「赤錆の鎚」のリーダーだった。東門の防衛中、群れから外れて南へ走る澱狼を見て、仲間に門を任せて単身で追った。南の村（ソラム）を守ったが、その間に門の戦線で仲間3人が死んだ。セラの弟レオンもその一人。膝の傷はこのときのもの。
- **悩み**：自分の選択が正しかったのか、7年間答えが出ていない。教官を続ける資格があるのか迷い、今季限りで辞めることを考えている。
- **価値観**：無謀を嫌う。研究者が若い冒険者を危険な調査に使うことを憎んでいる（ノインとの対立）。
- **秘密の結節点**：主人公の認識票は彼のもの。信頼が深まった後に見せると、彼の7年が報われる大きな場面になる。ただし時機を誤ると拒絶される。
- **関係の動き方**：口先には反応しない。訓練の継続と、危険から生きて帰ることで尊敬と信頼が育つ。無謀な行動には警戒が上がる。

### リーネ・アーデル（同期）
- 17歳。主人公と同じ日に仮登録した。
- 王都の小貴族アーデル家の庶子。家付きの騎士から剣の手ほどきを受けており、剣の才は確か。
- 誇り高く、せっかちで、正直。負けず嫌い。
- **本音**：家に「いてもいなくても同じ」と扱われてきた。自分には剣しかない、その剣で名を上げなければ自分には価値がない、と思い込んでいる。
- **目標**：一年で銅級に上がり、家に手紙を書くこと。
- **関係**：競争心と友情が同居する。主人公が剣で上回ると嫉妬が出るが、同時に認めもする。
- **アーク**：20日目前後に、等級外の依頼（澱熊の痕跡調査）に一人で行こうとする。主人公の関わり方によって、①一緒に行く ②止める ③知らずに放置（重傷を負って帰る）に分かれる。

### セラ・ミドウ（ギルドの受付職員）
- 29歳。几帳面で規則に厳しい。新人には特に厳しい。
- **過去**：弟レオンは「赤錆の鎚」の一員で、7年前の大潮で死んだ。ガラドを表立って責めはしないが、彼とは必要以上に口をきかない。
- **目標**：新人の訓練を義務化する「新人保護規定」を支部長に通すこと。夜に一人で草案を書き続けている。
- **悩み**：規則で人は守れるのか。弟は規則を守っていたのに死んだ。
- **関係**：主人公が依頼を確実にこなし、無謀をしなければ信頼が育つ。依頼の失敗や、期限を破ることを嫌う。

### ノイン（魔導院分室の研究員）
- 森人。見た目は20代だが、実年齢は60を超える。性別は女性。
- 好奇心が強く、率直で、社交性に欠ける。悪気なく失礼なことを言う。独特のやり方で優しい。
- **目標**：澱潮の予測。今年の大潮が記録より大きくなることを示す**潮計**を完成させたい。しかし誰も聞く耳を持たない。
- **過去**：清林の一族は、澱を「森の病」として触れることを禁じている。その禁を破って研究を始めたため、一族を出た。
- **関係**：主人公が知識を示すこと、サンプル採取に協力することで尊敬と信頼が育つ。危険な依頼をさらりと頼んでくる。
- **アーク**：潮計の完成（主人公の協力度による）→ 大潮の予測 → 守備隊とギルドを動かせるか（セラの規定・主人公の等級・信頼が絡む）。

### 脇役

- ボルド：ギルドの支部長。商会との関係を重視する現実主義者。
- 守備隊のハンス隊長（第1章後半で登場予定）。
