# 物語構成（ネタバレ）

## 層構造
1. **世界の時計**：主人公と無関係に進む出来事（下表）
2. **主要アーク**：大潮と、灯脈の謎
3. **人物アーク**：ガラド／リーネ／セラ／ノイン
4. **ストーリーレット**：日常の短い出来事（条件がそろうと発生）

## 第1章後半の実装メモ
- 潮計の進み具合（`tideGauge` 0〜3）：泥の試料（q_sample）、標石の欠片（q_ruin）、城壁での調整（calibrate）
- 予測（46日目以降に分室で。52日目以降はノインが宿まで探しに来る。未遭遇なら噂として流れる）
- 警告：支部長ボルドの説得 → `guildPrepared`。ガラドの口利き、または自力で守備隊のハンスを説得 → `garrisonPrepared`
- リーネ：40日目に縁談の手紙 → 3日後に残るか去るかが決まる（関係と助言による）→ パーティー（`lyneParty`）
- セラ：52日目に規定が採用されるか差し戻されるか（`ruleAdopted`）。ガラドとの和解（`seraGaradReconciled`）は主人公が仲立ちする
- ガラド：58日目に辞めるか続けるか。大潮の後に、戻るか南の村へ去るか
- 大潮の夜（78日目）：第一波 → 群れ長 → 「南の開拓村か、門か」という、七年前のガラドと同じ選択
  - 備えが0で、主人公が門を離れ、ガラドが門に立ち、リーネがいない → ガラドが死ぬ
- 後日譚：昇格、ノインの発見（脈動の中心はカルナスの真下＝第2章への引き）、ガラドの答え、エピローグ（90日目）

## 大潮の夜の結果を決める要素（予定）
- ノインの予測が広まったか（潮計の完成度、セラ・支部長への伝達）
- 守備隊とギルドが連携できたか
- ガラドの状態（教官を続けているか、主人公に過去を語ったか）
- リーネの状態（負傷しているか、主人公との関係）
- 主人公の実力と等級

## 主題（F2：おまかせ）
**「選ばなかった方の道」と、それでも生きて帰ること。**
- ガラドは村を選び、仲間を失った。
- リーネは選ばれなかった子だった。
- セラは規則を選び、それでも弟を失った。
- ノインは一族ではなく真実を選んだ。
- 主人公は、彼らの選択の結果の上に立っている。そして自分も選び続ける。
