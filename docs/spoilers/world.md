# 世界観（ネタバレ）

## 骨格（A2：おまかせ → α＋β 融合、γ は深層として温存）

### 歴史
- **旧天文明エクラ**：大陸ルーメア全土に「灯脈（とうみゃく）」と呼ばれる魔力の配給網を張り巡らせた古代文明。魔力は誰にとっても水や火のように身近だった。
- **大落日（たいらくじつ）**：412年前。灯脈が一夜にして断裂した。原因は記録に残っていない。断裂した脈から漏れ出した魔力は沈殿して濁り、**澱（おり）**となった。
- 澱は生き物を変質させ、**魔物**を生む。澱が濃く溜まった土地が**魔境**。
- 灯脈の「節（ふし）」があった場所ほど澱が濃い。
- **【深層の秘密（γ）】**：世界の魔力は大落日以降、ゆっくりと薄れ続けている。澱は「死んだ魔力」ではなく、まだ還流できる魔力でもある。澱結晶を燃料として燃やし続ける現在の文明は、残された魔力を食い潰している。第2章以降の主題。

### 澱潮（おりしお）
- 魔境の澱は、地下の節の「脈動」に合わせて周期的に満ち引きする。
- 毎季ごとの小さな潮と、**およそ7年ごとの大潮**がある。
- 大潮では魔物が魔境の外へ溢れ出す。
- **前回の大潮は7年前**で、主人公の村まで魔物が流れてきた。今年が次の大潮の年にあたる。
- 記録上、大潮の規模は回を追うごとに大きくなっている。ただし、それに気づいているのはノインだけ。

## 舞台：辺境都市カルナス
- ヴァルディア王国の東の果て、魔境「**灰縁の森（はいべりのもり）**」の縁に160年前に築かれた城塞都市。人口およそ8千。
- 存在理由は**澱結晶（魔核）**の採取。魔物の体内で澱が凝ったもので、魔導灯・魔導具の燃料として王国中で需要がある。
  - これがカルナスの経済のすべて。魔物が減れば街は貧しくなる、という矛盾を抱えている。
- 街の真下に、かつての灯脈の節が眠っている（誰も知らない。第1章終盤の伏線）。

### 社会構造
- **王国軍・辺境守備隊**：街の防衛を担う。ギルドを「金で動く無頼の集まり」と見下しがちで、ギルド側も守備隊を「門の内側でふんぞり返る連中」と見ている。
- **冒険者ギルド**：王国公認の互助組織。等級は仮登録 → 石 → 銅 → 鉄 → 銀 → 金 → 星。新人の死亡率が高いことが長年の課題になっている。
- **ベルク商会**：魔核の流通を握る大商会。ギルドの最大の取引先。
- **魔導院**：王都の学府。分室は予算を削られ、軽んじられている。

## 種族
- **人間**：王国の主要種族。
- **森人（もりびと）**：澱の届かない森の深部の「清林」に住む長命種。耳が少し尖っている。外界との交わりはほとんどない。澱について独自の伝承を持つ。ノインは一族を出奔した変わり者。
- （拡張予定）**岩窟の民**など。

## 魔法体系（A5：学問型を主軸）
- 魔法とは、体内の魔力を**術式**（意識の中で組む記号の構造）によって現象に変える技術。
- 実技（魔力の操作）と理論（術式の理解）の両輪で上達する。
- 大落日以前は灯脈から魔力を引けたため、強大な術が使えた。いまは個人の体内の魔力しか使えないので、多くの古代術式が「重すぎて」発動しない。
- 澱を燃料に使う魔導具は、魔力の少ない者でも使える。
