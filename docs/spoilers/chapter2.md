# 第2章「灯脈の節」設計（ネタバレ・草案）

- 期間：91〜180日目（陽月〜穂月、夏）
- 主題：**「燃やして生きるか、還して生きるか」**。第1章の「選ばなかったほうの道」を、個人から街の規模へ広げる。

## 骨格
1. **発端（91〜105日）**：大潮の夜の潮計の記録（`knowNode`）が王都に届く。魔導院の本院から調査官アウレリアが派遣される。同じ頃、商会主ゴドウィン・ベルクも「街の下に眠る巨大な魔核」の噂を嗅ぎつけて来る。
   - `knowNode` が偽の場合は、ノインとエドガーの調査が遅れて始まる（発端が約10日ずれる）。
2. **所属の選択（B4の本格実装）**：主人公に複数の誘いが来る。掛け持ちはできるが、義務の時間で自然に制約される。
   - 冒険者ギルド：鉄級の昇級審査。地下探索の正式依頼。
   - 魔導院分室の助手：ノインの推薦が必要。給金と書庫の深部。週に2つの時間帯の研究義務。
   - ベルク商会の調査役：エドガー、またはゴドウィン経由。報酬が高い。発掘隊の護衛。
   - 守備隊の臨時兵：ハンス経由。門と地下水道の警備。
3. **地下（110〜160日）**：カルナスの旧水道から、大落日以前の遺構へ。**探索マップ（ノードグラフ）を初めて本格実装**する（G6）。
   - 灯脈の節の間：澱が結晶化した巨大な「心臓」。節は弁であり、潮は節が流れを取り戻そうとする脈動だった。
4. **真相（γの開示）**：大落日以降、世界の魔力は薄まり続けている。魔核を燃やす文明は、その残りを食い潰している（エドガーの数字が裏づけになる）。
5. **決断（170日前後）**：街の真下の節をどうするか。
   - **封じる**（アウレリア寄り）：潮はほぼ止まる。魔物が減り、魔核経済が崩れる。街の存在理由が揺らぐ。薄まりは止まらない。
   - **掘る**（ゴドウィン）：巨大な魔核で街は空前の繁栄を得る。だが薄まりは加速し、数年後にもっと大きな潮が来る。
   - **還す**（ノイン＋エドガー）：節を「開き」、流れを戻す。成功すれば地域に魔力が還る。準備（理論・人手・守りの備え）が足りなければ、大潮を超える災厄になる。
   - 誰の側にも立たず、街を去る選択もある。
6. **余波と章の総括（180日）**

## 新しい主要NPC（最大10人まで）
- **アウレリア・ヴェイル**（魔導院本院の調査官）：冷徹な合理主義者。ノインの元同僚で、彼女を追放した側の一人。正しいが、冷たい。
- **ゴドウィン・ベルク**（商会主）：悪役ではない。貧しさを知る者として「燃やして豊かになる」ことを信じている。
- **イスラ**（森人の長老）：ノインの師。伝承と科学の対立を体現する。

## 実装状況（v0.4）
- 済：所属の仕組み、探索マップの仕組み、発端（ch2_start）、アウレリア来訪、ゴドウィン来訪、所属の誘い（分室・商会・守備隊）、旧水道の第1層（壁画、封じられた扉、標石の間）、話し合い（town_meeting：封じる／掘る／還す）
- 主人公の傾き：`ch2Lean`。扉の鍵：`needDoorHelp` → ノインの話題 → `doorKey` → `doorOpen` → `foundHall`
- 次：崩落の先（第2層）、人物アーク（リーネの兄、イスラ、灯り亭の立ち退き、エドガーと父）、決断
