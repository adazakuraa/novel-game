# 03. MVP 開発状況（ネタバレなし）

- 版: v0.1（2026-11-13）

## 実装済み
- キャラクター作成：名前・性別・一人称・難易度。生い立ちの描写から素質を推し量る（振り直しは無制限）
- 初期能力のランダム生成（才能の型の抽選、細部の揺らぎ、総量の正規化）
- 隠れた成長モデル
  - 行動は「未定着の経験」を生み、睡眠で定着する
  - 経験の難しさと今の実力の差、同じ行動の繰り返しによる逓減、体調、適性、指導者が伸び方に影響する
  - 技能には壁があり、実技・理論・実戦・指導のうち異なる種類の経験を積むと越えられる
  - 使わない技能の勘は少しずつ鈍る
  - 成長は、行動の描写の変化・日誌・周囲の反応・「自分を振り返る」の文章でのみ伝わる
- 時間：1日4区分。行動ごとに消費する時間帯が決まっている。生活費・空腹・疲労・負傷・ストレス
- 行動の組み立て：場所 → 活動 → 方法 → 重点 → 相手。6つの場所で約30種類
- 主要NPC4人：多軸の関係（信頼・親しみ・尊敬・恩義・警戒・競争心）。1日あたりの変化量に上限があり、関係は積み重ねでしか動かない。記憶・居場所のスケジュール・段階的に開く話題
- 物語：世界の時計に沿ったイベント（現状はおよそ30日分）、人物アーク、日常の出来事、依頼5種、昇級審査
- 戦闘：距離・予兆・読み・有利不利・負傷・逃走・道具・術。一度助けられた後の敗北は死につながる
- セーブ：自動保存、その日の朝への巻き戻し（標準）、手動3枠（標準）、JSON書き出し・読み込み
- 自動テスト：ランダムプレイを45日間実行して整合性を確認、成長曲線の確認
