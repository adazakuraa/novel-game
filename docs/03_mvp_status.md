# 03. MVP 開発状況（ネタバレなし）

- 版: v0.4（2026-11-14）

## 実装済み
- キャラクター作成：名前・性別・一人称・難易度。生い立ちの描写から素質を推し量る（振り直しは無制限）
- 初期能力のランダム生成（才能の型の抽選、細部の揺らぎ、総量の正規化）
- 隠れた成長モデル
  - 行動は「未定着の経験」を生み、睡眠で定着する
  - 経験の難しさと今の実力の差、同じ行動の繰り返しによる逓減、体調、適性、指導者が伸び方に影響する
  - 技能には壁があり、実技・理論・実戦・指導のうち異なる種類の経験を積むと越えられる
  - 使わない技能の勘は少しずつ鈍る
  - 成長は、行動の描写の変化・日誌・周囲の反応・「自分を振り返る」の文章でのみ伝わる
- 時間：1日4区分。行動ごとに消費する時間帯が決まっている。生活費・空腹・疲労・負傷・ストレス
- 行動の組み立て：場所 → 活動 → 方法 → 重点 → 相手。6つの場所で約30種類
- 主要NPC4人：多軸の関係（信頼・親しみ・尊敬・恩義・警戒・競争心）。1日あたりの変化量に上限があり、関係は積み重ねでしか動かない。記憶・居場所のスケジュール・段階的に開く話題
- 物語：第1章「澱潮の春」を最後まで（90日、エピローグあり、その後も自由に続けられる）。人物アーク、日常の出来事、依頼6種、昇級審査
- 自由入力の行動検索：したいことを文で書くと、辞書と文字の並びの近さから行動の候補を出す（生成AIは使わない）
- 主要NPCを6人に（宿の女将、商会の若者を追加）。宿代を待ってもらう「ツケ」、宿の手伝い
- 危険の予告：一度助けられた後の単独行動での警告。助けの来ない戦いでは、一度だけ踏みとどまって最後の警告を出す
- 第2章「灯脈の節」の序盤（91〜110日目ごろ）。主要NPCは7人に
- 所属（職業）：魔導院分室・ベルク商会・守備隊。掛け持ちできる。それぞれ週ごとの務め（時間帯）と給金があり、務めを怠り続けると籍を外される（ギルドの冒険者としての身分は常に維持）
- 地下の探索マップ：地点のつながりを移動する。三歩ごとに時間が進み、松明が減る。調べる、仕掛けを解く、遭遇戦、地上への帰還。夜になる前に自動で引き上げる
- タイトル画面に、実装済みの章を表示
- 仲間：条件を満たすと、森での採取や狩りに仲間を連れて行ける
- 潮の時期：森の危険度の上昇、城壁の夜警
- 戦闘：距離・予兆・読み・有利不利・負傷・逃走・道具・術。一度助けられた後の敗北は死につながる
- セーブ：自動保存、その日の朝への巻き戻し（標準）、手動3枠（標準）、JSON書き出し・読み込み
- 自動テスト：ランダムプレイを115日間（8通り。警告を無視しない想定で全員が生還）、大潮の夜の主な分岐、自由入力の検索、所属の週ごとの清算、地下探索の道筋、成長曲線の確認

## 自由入力の限界（C1）
- 辞書にある言葉と、行動名・説明文との文字の並びの近さで判定する。辞書にない言い回しや、否定（「〜しない」）、複数の行動を一度に頼む文は正しく解釈できない
- 想定外の行動を新しく作り出すことはできない。既存の行動の中から近いものを提案するだけ

## 既知の制約
- セーブはブラウザ内の保存領域に置かれる。ブラウザのデータを消すと失われるので、「記録」タブから書き出してバックアップしてください
